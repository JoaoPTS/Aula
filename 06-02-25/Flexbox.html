FlexBox

Para utilizar o flexbox é preciso um container flex


.container {
    display: flex;
}

O flexbox é uma maneira de organizar os elementos dentro de um container, permitindo que eles se ajustem automaticamente ao espaço disponível.

Propriedades do container Flex

Flex-Direction

Define a direção dos itens dentro do container flex.

Flex-Wrap

Define se os itens devem quebrar para a próxima linha quando não houver espaço suficiente.

Justify-Content

Alinha os itens ao longo do eixo principal do container.

Align-Items

Alinha os itens ao longo do eixo transversal do container.

Align-Content

Alinha as linhas do container quando há espaço extra no eixo transversal.
