Header - Elementos Semânticos

Permite estabelecer a área de cabeçalho dapágina, normalmente contém títulos, imagens

Nav - Elementos Semânticos

Define uma área de navegação, normalmente contém links para outras páginas ou seções do site

Exemplo:

  • 1
  • 2
  • 3

Section - Elementos Semânticos

Define uma seção genérica de conteúdo, pode conter outros elementos semânticos como artigos, cabeçalhos, parágrafos, etc.

Article - Elementos Semânticos

Define um artigo independente, pode conter títulos, parágrafos, imagens, etc.

Aside - Elementos Semânticos

Define conteúdo relacionado, como uma barra lateral, normalmente contém informações adicionais ou links relacionados ao conteúdo principal

Footer - Elementos Semânticos

Define o rodapé da página, normalmente contém informações de copyright, links de contato, etc.

Exemplo:

© 2025 - FATEC Presidente Prudente
