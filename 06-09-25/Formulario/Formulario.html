Elemento Form

O elemento <form> define o formulário que será utilizado para coletar os dados. O formulário pode possuir diferentes elementos, como campos de texto, checkboxs, radio buttons, submit buttons, entre outros

Exemplo de Formulario:

<form action="https://www.exemplo.com/submit" method="post">
  <label for="nome">Nome:</label>
  <input type="text" id="nome" name="nome" required>
  <br>
  <label for="email">Email:</label>
  <input type="email" id="email" name="email" required>
  <br>
  <input type="submit" value="Enviar">
</form>

Elemento Input:

O elemento <input> é utilizado para criar campos de entrada de dados no formulário. Ele pode ter diferentes tipos, como texto, email, senha, checkbox, radio, entre outros.

<input type="text" id="nome" name="nome" required>
<input type="email" id="email" name="email" required>
<input type="password" id="senha" name="senha" required>

Elemento Label:

O elemento <label> é utilizado para associar um rótulo a um campo de entrada. Ele melhora a acessibilidade e a usabilidade do formulário.

<label for="nome">Nome:</label>

Elemento Button:

O elemento <button> é utilizado para criar botões no formulário. Ele pode ser usado para enviar o formulário ou executar outras ações.

<button type="submit">Enviar</button>
<button type="reset">Limpar</button>
<button type="button" onclick="alert('Botão clicado!')">Clique Aqui</button>

Elemento Textarea:

O elemento <textarea> é utilizado para criar um campo de texto multilinha no formulário. Ele permite que o usuário insira texto longo.



<textarea id="mensagem" name="mensagem" rows="4" cols="50" required></textarea>

Elemento Date

O elemento <input type="date"> é utilizado para criar um campo de entrada de data. Ele permite que o usuário selecione uma data específica.

<input type="date" id="data" name="data" required>

Elemento DateTime-Local

O elemento <input type="datetime-local"> é utilizado para criar um campo de entrada de data e hora. Ele permite que o usuário selecione uma data e hora específicas.

<input type="datetime-local" id="dataHora" name="dataHora" required>

Elemento Time:

O elemento <input type="time"> é utilizado para criar um campo de entrada de hora. Ele permite que o usuário selecione uma hora específica.

<input type="time" id="hora" name="hora" required>

Elemento Month

O elemento <input type="month"> é utilizado para criar um campo de entrada de mês e ano. Ele permite que o usuário selecione um mês e um ano específicos.

<input type="month" id="mes" name="mes" required>

Elemento Radio Button

O elemento <input type="radio"> é utilizado para criar botões de opção. Ele permite que o usuário selecione uma única opção entre várias disponíveis.



<input type="radio" id="opcao1" name="opcao" value="opcao1" required>

Elemento Checkbox

O elemento <input type="checkbox"> é utilizado para criar caixas de seleção. Ele permite que o usuário selecione uma ou mais opções.



<input type="checkbox" id="opcao1" name="opcao1" value="opcao1">

Elemento Fieldset

O elemento <fieldset> é utilizado para agrupar elementos de formulário relacionados. Ele melhora a organização e a legibilidade do formulário.

Informações Pessoais
<fieldset><legend>Informações Pessoais</legend></fieldset>

Elemento Select

O elemento <select> é utilizado para criar uma lista suspensa de opções. Ele permite que o usuário selecione uma opção entre várias disponíveis.

<select id="opcoes" name="opcoes" required></select>

Elemento Datalist

O elemento <datalist> é utilizado para criar uma lista de opções pré-definidas que podem ser sugeridas ao usuário enquanto ele digita em um campo de entrada.

<datalist id="frutas"></datalist>

Elemento Color

O elemento <input type="color"> é utilizado para criar um campo de entrada de cor. Ele permite que o usuário selecione uma cor específica.

<input type="color" id="cor" name="cor" required>

Elemento File

O elemento <input type="file"> é utilizado para criar um campo de entrada de arquivo. Ele permite que o usuário selecione um ou mais arquivos para enviar.


<input type="file" id="arquivo" name="arquivo" required>
