Elemento Form

O elemento <form> define o formulário que será utilizado para coletar os dados. O formulário pode possuir diferentes elementos, como campos de texto, checkboxs, radio buttons, submit buttons, entre outros

Exemplo de Formulario:

<form action="https://www.exemplo.com/submit" method="post">
  <label for="nome">Nome:</label>
  <input type="text" id="nome" name="nome" required>
  <br>
  <label for="email">Email:</label>
  <input type="email" id="email" name="email" required>
  <br>
  <input type="submit" value="Enviar">
</form>

Elemento Input:

O elemento <input> é utilizado para criar campos de entrada de dados no formulário. Ele pode ter diferentes tipos, como texto, email, senha, checkbox, radio, entre outros.

<input type="text" id="nome" name="nome" required>
<input type="email" id="email" name="email" required>
<input type="password" id="senha" name="senha" required>
