Atributos de Formulários

Os atributos de formulários são usados para definir o comportamento e a aparência dos campos de entrada em um formulário HTML.

Atributo Value

Especifica um valor inicial para um campo

Atributo Disabled

Desabilita um campo de entrada, tornando-o não editável e não enviável



Atributo Readonly

Permite que o campo seja visualizado, mas não editado



Atributo Size

Define a largura do campo de entrada em número de caracteres


Atributo Maxlength

Limita o número máximo de caracteres que podem ser inseridos no campo


Atributo Minlength

Define o número mínimo de caracteres que devem ser inseridos no campo


Atributo Autocomplete

Habilita ou desabilita o preenchimento automático do campo


Atributo Max e Min

Define os valores máximo e mínimo permitidos para campos numéricos



Atributo Pattern

Define uma expressão regular que o valor do campo deve corresponder


Atributo Autofocus

Define que o campo deve receber o foco automaticamente quando a página é carregada

<input type="text" id="nome" name="nome" autofocus>

Atributo Required

Indica que o campo é obrigatório e deve ser preenchido antes do envio do formulário


Atributo Placeholder

Exibe um texto de dica dentro do campo de entrada quando ele está vazio
